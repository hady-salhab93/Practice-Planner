# Triage Labels

The skills use five canonical triage roles. These are the corresponding GitHub label strings for this repo.

| Canonical role    | GitHub label      | Meaning                                               |
| ----------------- | ----------------- | ----------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | A maintainer needs to evaluate the issue              |
| `needs-info`      | `needs-info`      | Waiting for information from the reporter             |
| `ready-for-agent` | `ready-for-agent` | Fully specified and approved for agent implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation                         |
| `wontfix`         | `wontfix`         | Will not be actioned                                  |

When a skill mentions a canonical role, use its mapped label. Do not apply `ready-for-agent` unless agent implementation is approved for that issue.
